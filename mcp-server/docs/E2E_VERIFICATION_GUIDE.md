### Health Check (No Auth Required)
```
GET https://secure-rag-mcp.onrender.com/health
Accept: application/json
```

Expected Response (200 OK):
```json
{
  "status": "healthy",
  "details": {...}
}
```

### MCP Endpoint Base URL
```
POST https://secure-rag-mcp.onrender.com/mcp
Content-Type: application/json
Accept: application/json
```

**NOTE**: Current implementation does NOT validate Authorization header at HTTP layer yet.  
The token validation infrastructure exists (`authenticate_request()`, `validate_mcp_token()`) but is not wired into mcp_endpoint().

## 7. Successful Response Look

**HTTP Status**: 200 OK

**Response Structure**:
```json
{
  "jsonrpc": "2.0",
  "id": <request_id>,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "<answer>\n\n**Sources:**\n<source_citations>\n\n_Retrieved <N> document(s) from <dept>_"
      }
    ],
    "isError": false
  }
}
```

**Important Fields**:
- `content[0].text` → Contains answer + source citations (formatted by MCP tool)
- `sources` in tool response → Document metadata (name, department, page range, relevance score)
- `isError: false` → Success indicator
- All sources filtered by user's department (ACL enforced by backend)

## 8. Check Render Logs

### MCP Service
- **Service**: `secure-rag-mcp` on Render
- **Look for**:
  - `"MCP request: tools/list"` → Health indicator
  - `"MCP request: tools/call"` → Tool invocation
  - `"Tool invoked: ask_knowledge_base | user_id=..."` → Tool start
  - `"Tool completed: ask_knowledge_base | sources=..."` → Tool end
  - ✅ If missing: Auth context is null (token validation not yet wired to HTTP layer)

### Backend Service
- **Service**: `securerag-backendd` on Render
- **Look for**:
  - `POST /api/chat` → Chat request received
  - `Retrieved X documents from Qdrant` → Retrieval success
  - `user_department_name: <dept>` → ACL filter applied
  - `Answer generated by LLM` → Generation success
  - ✅ Check department filter is working (logs show filtered sources)
